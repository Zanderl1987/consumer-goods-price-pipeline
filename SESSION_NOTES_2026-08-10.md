## Pattern worth flagging

A repo can be reconciled commit-wise and still be functionally missing its
keys: git merge and `.env` state are orthogonal. The 08-04 activation work
proved the pipelines work against those keys, but the key values live on
whichever machine/clone pasted them — verify `.env` presence (key *names*,
never values) as part of any cross-clone reconcile.
